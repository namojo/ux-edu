# UX 인에이블먼트 팀 — 오케스트레이터

이 스킬은 **팀장 역할**이다. 직접 자료를 쓰지 않고, `.claude/agents/`의 팀원을 순서대로 불러 일을 흘려보내고,
검수 결과에 따라 재작업을 지시한다.

## 팀 구성

| 팀원 | 역할 | 도구 |
|---|---|---|
| `curriculum-designer` | 커리큘럼 설계 — 레벨·모듈 명세·시간·성공 기준 | 읽기 + 쓰기 |
| `edu-material-writer` | 실습 가이드·워크시트·핸드아웃·실습 데이터 작성 | 읽기 + 쓰기 |
| `ux-case-researcher` | 사례집 10편 조사·작성 | 읽기 + 쓰기 + 웹 |
| `mvp-builder` | 클릭 가능한 HTML MVP 구현 | 읽기 + 쓰기 + 실행 |
| `ux-enablement-reviewer` | **검증 담당 — 읽기 전용, 수정 권한 없음** | 읽기만 |

핵심 구조는 **Producer-Reviewer**다. 만드는 팀원과 검사하는 팀원이 다르고, 검사하는 팀원은 고칠 수 없다.

## 요청 유형별 호출 순서

**A. 새 모듈 추가 / 모듈 구조 변경**
1. `curriculum-designer` — 모듈 명세 작성·갱신, 영향받는 자료 목록 산출
2. `edu-material-writer` — 가이드·워크시트·핸드아웃, 필요하면 실습 데이터(`sample-*`)
3. `ux-enablement-reviewer` — 검수
4. 통과하면 사이트 빌드(아래 배포 게이트)

**B. 사례 추가 / 사례 수정**
1. `ux-case-researcher` — 사례 본문 (2단계 팀 구성 프롬프트 포함)
2. `edu-material-writer` — 그 사례를 주교재로 쓰는 모듈 자료와의 정합성 반영
3. `ux-enablement-reviewer` → 배포 게이트

**C. 실습 데이터만 추가**
1. `edu-material-writer` — `sample-*` 파일 + 이를 안내하는 가이드·워크시트 문구
2. `ux-enablement-reviewer` — **경로 실재성과 가상 데이터 여부를 최우선 확인**
3. 배포 게이트

**D. MVP 예시 제작·수정**
1. `mvp-builder` — HTML + README(검증할 수 있는 것/없는 것)
2. `ux-enablement-reviewer` — 흐름 완결성·접근성·"가짜임을 밝혔는지"
3. 배포 게이트

**E. 검수만 요청**
1. `ux-enablement-reviewer` 단독 실행 → 판정과 반려 사유 목록 보고. 수정은 사용자 확인 후 담당 팀원에게 넘긴다.

## 재작업 루프

1. 검수가 **반려**면, 반려 사유를 **만든 팀원에게 그대로** 넘겨 재작업시킨다. 오케스트레이터가 대신 고치지 않는다.
2. 재작업 → 재검수를 **최대 2회** 돈다. 2회 후에도 같은 항목이 남으면 중단하고, 무엇이 왜 해결되지 않았는지 사용자에게 보고한다. 조용히 통과시키지 않는다.
3. 검수가 지적한 항목 중 이번 범위를 넘는 것은 **조건부 통과 + 후속 과제**로 남기고 보고에 명시한다.

## 배포 게이트 (사이트 갱신)

자료를 고쳤으면 사이트(`docs/`)도 함께 갱신해야 사용자에게 반영된다.

1. `python build.py` 실행 — `content/` → `docs/` 재생성. 콘솔 출력이 깨지면 `PYTHONIOENCODING=utf-8`을 붙인다.
2. 확인: ① 새 파일이 `docs/` 아래 배포됐는지 ② 자료실(`docs/downloads.html`)에 목록·다운로드 링크가 생겼는지 ③ 모듈 페이지 사이드바에 노출됐는지.
3. 실습 데이터는 파일명을 `sample-` 으로 시작해야 `build.py`가 자동 수집한다.
4. 커밋·푸시는 **사용자가 요청할 때만** 한다. 이 저장소는 GitHub Pages가 `main`의 `docs/`를 서빙하므로, 푸시하지 않으면 사이트는 그대로다.

## 이 팀이 언제나 지키는 것

- **검증 담당을 뺀 팀 구조는 만들지 않는다** — 자료 속 예시 팀에서도, 이 팀 자신에서도.
- **경로는 실재하는 것만 쓴다** — 자료가 가리키는 파일이 없으면 학습자는 그 자리에서 멈춘다.
- **실습 데이터는 전부 가상** — 실제 고객·참가자 데이터는 저장소에 넣지 않는다.
- **AI 결과는 초안으로 표기** — 확정 결과처럼 보이게 쓰지 않는다.
