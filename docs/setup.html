하네스 설치 — 전체 사례집에서 처음 한 번만

약 2분설치는 전체 사례집·교육에서 딱 한 번입니다

revfactory/harness는 한 번 설치하면 어느 폴더·어느 사례에서든 계속 쓸 수 있습니다. 이 페이지의 설치는 딱 한 번만 하면 되고, 각 사례의 0단계는 "설치되어 있는지 확인"만 합니다.

설치 (약 2분)

Claude Code(터미널에서 대화하듯 쓰는 AI 도구) 대화창에 아래 두 줄을 한 줄씩 순서대로 입력합니다. 각 줄을 입력한 뒤 완료 메시지를 확인하고 다음 줄을 입력하세요.

복사해서 쓰세요
/plugin marketplace add revfactory/harness
복사해서 쓰세요
/plugin install harness@harness-marketplace

💡 이렇게 나오면 정상입니다: 설치에 수십 초가 걸리며 그동안 화면이 멈춘 듯 보일 수 있습니다. 빨간 에러 메시지가 뜨면 사내망·방화벽이 GitHub 접근을 막는 경우일 수 있으니 네트워크를 바꾸거나 관리자에게 문의하세요.

설치 확인

대화창에 /plugin을 입력해 설치된 목록에 harness가 보이면 준비 완료입니다. 확실하지 않으면 위 두 줄을 다시 실행해도 무해합니다 — 이미 설치되어 있으면 그냥 넘어갑니다.

참고

  • 플러그인(Claude Code에 기능을 더하는 확장)은 폴더와 무관하게 전역으로 설치됩니다 — 어느 세션에서 설치해도 전체에 적용됩니다.
  • 설치 후 사용법은 각 사례의 2단계("하네스 구성해줘")부터 시작합니다.
