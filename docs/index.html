AI 하네스로,
UX가 일하는 방식을 바꿉니다.

인터뷰 녹취 정리부터 클릭되는 시제품까지 — 반복 작업은 역할이 나뉜 AI 에이전트 팀(하네스)에게 맡기고, UX 전문가는 판단과 발견에 집중합니다. 이 교육은 도구 사용법이 아니라 일하는 방식의 전환을 다룹니다. 코딩은 필요 없습니다.

전환 로드맵 — 도구에서, 팀으로

AI에게 말을 거는 것(L1)에서 출발해, 자기 실무 데이터를 다루고(L2), 마지막에는 반복 업무를 AI 팀으로 설계(L3)하는 데까지 갑니다. 목적지는 도구 사용이 아니라 업무 구조의 재설계입니다.

L1 1회차

AI와 첫 대화

터미널을 처음 열고, 파일을 읽히고, 결과를 검증하는 법까지. 코딩 없이 한국어 문장만으로.

· AI에게 내 파일을 맡기는 첫 경험· 좋은 요청과 결과 검증 — 함정 피하기
가져가는 것 — 첫 성공 경험 + 환각·개인정보 검증 습관
L2 2회차

내 업무에 붙이기

자기 서비스의 진짜 데이터(VoC·인터뷰)를 가져와 실무 산출물의 초안을 만든다.

· 내 VoC 데이터로 개선 기회 뽑기· 내 리서치에서 인사이트·페르소나 만들기
가져가는 것 — 내 서비스 VoC 개선 기회 + 페르소나·저니맵 초안
L2+L3 3회차

시제품과 나만의 하네스

아이디어를 클릭되는 시제품으로 만들고, 반복 업무를 AI 팀(하네스)으로 설계한다.

· 내 아이디어를 클릭되는 시제품으로· 반복 업무 하나를 나만의 AI 팀으로
가져가는 것 — 클릭되는 MVP + 반복 업무의 하네스 설계 캔버스

6개 모듈

각 90분. 실습 가이드는 화면에 보이는 그대로 따라 할 수 있게 쓰여 있고, 막히기 쉬운 곳마다 "이렇게 나오면 정상입니다" 안내가 있습니다.

01 L1

AI에게 내 파일을 맡기는 첫 경험

터미널을 열고, 폴더의 파일을 읽혀, 첫 결과를 받아낸다.

⏱ 90분 02 L1

좋은 요청과 결과 검증 — 함정 피하기

후속 프롬프트로 결과를 다듬고, 환각·개인정보를 스스로 검증한다.

⏱ 90분 03 L2

내 VoC 데이터로 개선 기회 뽑기

자기 서비스의 리뷰·CS 티켓에서 주제별 개선 기회 초안을 만든다.

⏱ 90분 04 L2

내 리서치에서 인사이트·페르소나 만들기

인터뷰 데이터를 어피니티 종합 → 페르소나·저니맵 초안으로 잇는다.

⏱ 90분 05 L2

내 아이디어를 클릭되는 시제품으로

아이디어를 사용성 테스트용 HTML MVP 초안으로 만든다.

⏱ 90분 06 L3

반복 업무 하나를 나만의 AI 팀으로

반복 업무 1개를 역할 나눈 에이전트 팀(하네스) 설계로 옮긴다.

⏱ 90분+과제

활용 사례집 — 10가지 실무 레시피

교육이 끝난 뒤에도 책상에 두고 쓰는 참조 자산. 모든 사례에 복사해 쓰는 프롬프트와 "꼭 사람이 확인하세요" 체크가 들어 있습니다.
