AI 하네스로,
UX가 일하는 방식을 바꿉니다.

인터뷰 녹취 정리부터 클릭되는 시제품까지 — 반복 작업은 역할이 나뉜 AI 에이전트 팀(하네스)에게 맡기고, UX 전문가는 판단과 발견에 집중합니다. 이 교육은 도구 사용법이 아니라 일하는 방식의 전환을 다룹니다. 코딩은 필요 없습니다.

전환 로드맵 — 도구에서, 팀으로

AI에게 말을 거는 것(L1)에서 출발해, 자기 실무 데이터를 다루고(L2), 마지막에는 반복 업무를 AI 팀으로 설계(L3)하는 데까지 갑니다. 목적지는 도구 사용이 아니라 업무 구조의 재설계입니다.

L1 1회차

첫 대화, 첫 하네스

Claude Code와 첫 대화를 나누고, 하네스를 설치해 그날 바로 첫 에이전트 팀을 구성해 본다.

· Claude Code 열고 하네스 설치까지· 하네스 구성해줘 — 내 손으로 만든 첫 팀
가져가는 것 — 내 손으로 구성한 첫 하네스 팀
L2 2회차

내 업무를 팀에게

자기 서비스의 진짜 데이터(VoC·인터뷰)로 분석 팀을 구성·실행하고, 검증 담당의 결과를 확인한다.

· VoC 분석 팀을 만들어 내 리뷰 돌리기· 리서치 종합 팀 → 페르소나 팀 잇기
가져가는 것 — 내 데이터로 돌린 VoC 팀 + 페르소나 파이프라인
L2+L3 3회차

시제품, 그리고 팀 설계자

MVP 팀으로 시제품을 만들고, 자기 반복 업무를 역할 분해해 하네스로 직접 설계·진화시킨다.

· MVP 팀으로 클릭되는 시제품 만들기· 내 반복 업무를 팀 구조로 직접 설계·진화
가져가는 것 — 클릭되는 MVP + 실행되는 나만의 하네스

6개 모듈

각 90분, 핸즈온 50% 이상. 첫날 안에 첫 하네스를 구성하고, 마지막 모듈에서는 자기 반복 업무의 팀을 직접 설계합니다. 막히기 쉬운 곳마다 "이렇게 나오면 정상입니다" 안내가 있습니다.

01 L1

Claude Code 열고 하네스 설치까지

Claude Code를 켜 파일을 다루고, revfactory/harness 플러그인을 설치한다.

⏱ 90분 02 L1

하네스 구성해줘 — 내 손으로 만든 첫 팀

자연어로 첫 하네스를 구성·실행하고, 팀에 검증 담당이 있는 구조를 이해한다.

⏱ 90분 03 L2

VoC 분석 팀을 만들어 내 리뷰 돌리기

자기 VoC 데이터로 분석 팀을 구성·실행하고 검증 결과를 사람이 확인한다.

⏱ 90분 04 L2

리서치 종합 팀 → 페르소나 팀 잇기

두 하네스를 연결해 자기 인터뷰에서 페르소나·저니맵 초안까지 만든다.

⏱ 90분 05 L2

MVP 팀으로 클릭되는 시제품 만들기

구현·검수 팀을 구성해 자기 아이디어를 클릭 가능한 HTML MVP로 만든다.

⏱ 90분 06 L3

내 반복 업무를 팀 구조로 직접 설계·진화

반복 업무를 역할 분해·검증 단계로 직접 설계해 구성하고, 실행 결과로 진화시킨다.

⏱ 90분+과제

사례집 — 바로 구성할 수 있는 10개의 팀

모든 사례가 같은 뼈대를 따릅니다 — 하네스 설치 → "하네스 구성해줘"(팀 구성 프롬프트) → 팀 실행 → 피드백으로 팀 진화. 복사해 쓰는 구성 프롬프트와 "꼭 사람이 확인하세요" 체크 포함. 처음이라면 하네스 설치 (처음 한 번만, 2분)부터.
