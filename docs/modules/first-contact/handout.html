폴더 만들기 → 터미널 열기 → claude 입력 → 아래 프롬프트로 요약 요청 → 결과 확인 → 후속 요청으로 다듬기 → 하네스 설치

2. 터미널 열기 (macOS) & 확인·실행

macOS 방법 B · cd로 이동 (기본) macOS 방법 A · 폴더에서 바로 열기 (보조) Windows
Cmd+Space → "터미널"(영문 환경이면 "Terminal") 검색 실행 → cd 입력 → 작업 폴더를 창 위로 드래그앤드롭 → Enter 작업 폴더 우클릭 → "폴더에서 새 터미널 열기" (메뉴가 기본값으로 없을 수 있음 → 없으면 방법 B) 폴더 우클릭 → "터미널에서 열기" (없으면 주소창에 cmd 입력). 설치 때 쓴 것과 같은 터미널을 열 것

들어왔는지 확인: ls 입력(Windows cmd는 dir, PowerShell은 ls) → sample-reviews.txt가 보이면 OK → claude 입력 → 화면이 바뀌면 대화창 시작

3. claude 처음 켤 때 나오는 화면들

① 로그인/계정 ② 폴더 신뢰 확인 ③ 파일 접근 권한 확인
넘길 수 없는 실제 인증 화면. 사전 로그인이 안 됐다면 화면 안내를 그대로 따라 로그인부터 마친다. 처음 보는 폴더에서 한 번 묻는다. 우리 연습 폴더이므로 Yes, proceed 선택. 뜨면 1. Yes 선택 후 Enter. 창 없이 바로 결과가 나와도 정상(읽기 작업은 생략되기도 함) — 다른 사람과 달라도 걱정 말 것.

4. 하네스 설치 (그대로 복붙, 한 줄씩)

복사해서 쓰세요
/plugin marketplace add revfactory/harness
복사해서 쓰세요

설치 확인: 완료 메시지가 뜨는지 본다. 애매하면 /plugin 입력 → 목록에 harness가 보이면 완료.

5. 막히면 이렇게

command not found 경로 에러 (No such file/directory) 설치가 안 끝나는 것 같다 설치 중 빨간 에러 메시지
설치 문제. 에러 메시지를 Claude Code에 붙여넣고 해결법을 물어본다. 폴더를 다시 드래그앤드롭. 수십 초는 정상 대기. 그래도 안 끝나면 에러 메시지를 복사해 물어본다. 사내망·방화벽 문제일 수 있음. 에러 메시지를 그대로 복사해 물어보고, 안 되면 사내 헬프 채널 문의.
