슬라이드 개요 (강사용) — Claude Code 열고 하네스 설치까지

모듈: first-contact / L1 / 90분 / 도입·시연 30분 — 실습 45분 — 공유·정리 15분 완성 슬라이드가 필요하면 이 개요를 바탕으로 pptx 스킬로 제작 요청하세요. 아래는 슬라이드별 제목 + 강사가 말할 요점입니다.

Slide 1. 표지

  • 제목: Claude Code 열고 하네스 설치까지
  • 말할 요점: 오늘은 개념 수업이 아니라 직접 손으로 해보는 시간이라고 못 박는다. "90분 뒤 여러분 노트북에는 여러분이 직접 받은 AI 요약과, 다음 시간부터 팀을 만들 수 있는 하네스 설치까지 끝나 있을 것"이라고 목표를 먼저 던진다.

Slide 2. 오늘 배우는 것 (학습 목표)

  • 제목: 오늘의 목표
  • 말할 요점: (1) 터미널 열기 (2) 작업 폴더로 이동해 claude 켜기 (3) 폴더 안 파일을 읽혀 결과 받기 (4) revfactory/harness 플러그인 설치까지 마치기 — 이 네 가지를 "혼자서" 끝까지 해내는 것이 목표. 지식 습득이 아니라 손에 익히는 것임을 강조. 오늘은 팀을 "만드는" 게 아니라 "설치"까지만 한다는 것을 분명히 한다 — 팀 만들기는 다음 시간(first-harness).

Slide 3. 왜 "폴더"부터 만드나

  • 제목: Claude Code는 지금 있는 폴더만 본다
  • 말할 요점: Claude Code는 컴퓨터 전체를 뒤지는 게 아니라, 터미널이 열려 있는 그 폴더 안의 파일만 읽고 쓴다는 개념을 짧게 그림으로 설명(폴더 아이콘 + 그 안의 파일들). 그래서 "이번 작업용 폴더"를 매번 먼저 만드는 습관을 들인다고 연결.

Slide 4. (시연) 폴더 만들기 → 터미널 열기

  • 제목: 같이 해봅시다 — 1, 2단계
  • 말할 요점: 화면 미러링으로 실제 진행. 바탕화면 우클릭 → 새 폴더 → 이름 정하기 → 샘플 파일 넣기 → 방법 B를 기본 시연: 터미널 실행(Cmd+Space → "터미널") → cd 입력 후 폴더를 창 위로 드래그앤드롭 → Enter. 이 순서를 천천히, 마우스 움직임까지 보이며 시연. 방법 A(폴더 우클릭 "폴더에서 새 터미널 열기")는 이 메뉴가 기본값으로 꺼져 있는 Mac이 많으므로 "메뉴가 이미 켜져 있는 분만 쓰는 지름길"로 보조 언급만 한다 — 라이브 시연을 방법 A로 하면 메뉴가 없어서 막힌다. Windows 사용자는 별도 안내(가이드 참고 페이지) 언급.

Slide 5. (시연) claude 켜기

  • 제목: 같이 해봅시다 — 3단계
  • 말할 요점: 터미널에 claude 입력 → Enter → 화면이 바뀌는 순간을 보여준다. 이때 로그인/계정 화면과 "Do you trust the files in this folder?" 신뢰 확인 화면이 권한 확인 창(Slide 8)보다 먼저 나타날 수 있음을 미리 스크린샷으로 보여주고 순서를 짚어준다: (1) 로그인 화면 — 사전 인증이 안 된 사람은 여기서 멈추고 손을 들도록 안내(도입 30분에 로그인까지 끝냈는지 재확인), (2) 신뢰 확인 화면 — 우리가 만든 연습 폴더이니 "Yes, proceed"를 고르면 된다고 시연. 이 두 화면을 미리 보여주지 않으면 실습 중 가장 먼저, 가장 조용히 막히는 지점이 된다. 이후 언어·테마 등 초기 설정 화면이 있다면 그 자리에서 같이 넘긴다.

Slide 6. 프롬프트란 무엇인가

  • 제목: 프롬프트 = AI에게 보내는 요청 문장
  • 말할 요점: 어려운 코드가 아니라 그냥 한국어 문장을 치는 것뿐이라는 점을 강조. 오늘 쓸 첫 문장을 슬라이드에 크게 띄워서 다 같이 읽는다: "sample-reviews.txt 파일을 읽고 무슨 내용인지 3줄로 요약해줘." 여기서부터는 각자 실습(45분)으로 넘어간다고 예고.

Slide 7. 이제 여러분 차례 — 실습 시작 (45분)

  • 제목: 실습 시작
  • 말할 요점: 가이드(guide.md) 4~7단계(파일 읽히기 → 후속 요청 → 하네스 설치)를 각자 속도로 진행하도록 안내. TA가 자리를 돌며 권한 창·경로 문제를 즉시 잡아준다고 공지. 막히면 손을 들라고 명확히 안내(당황해서 조용히 포기하는 사람이 없도록).

Slide 8. (실습 중 안내) 권한 확인 창 — 뜨면 이렇게 대응

  • 제목: 이 창이 뜨면 이렇게 하세요 (안 떠도 정상입니다)
  • 말할 요점: 권한 확인 창 스크린샷을 미리 준비해 띄운다. "AI가 내 파일을 함부로 만지지 않도록 물어보는 안전장치"라고 설명하고, Yes를 선택해 진행하는 것까지 시연. 단, 이 창은 설정·버전에 따라 뜨지 않고 바로 결과가 나올 수도 있다는 것을 반드시 같이 언급한다 — 옆 사람은 창이 떴는데 내 화면은 안 떴다고 해서 잘못된 게 아니라고 미리 안심시켜야, 창이 없는 학습자가 "나만 뭔가 잘못했다"고 오해해 조용히 이탈하지 않는다. 요약 결과를 받은 뒤 "방금 요약을 표로 다시 보여줘"를 이어 입력해 결과가 바뀌는 것도 함께 보여준다 — "한 번 던지고 끝이 아니라, 이어서 다듬을 수 있다"는 체감 포인트.
  • 강사 노트(사전 리허설 필수): 이 슬라이드로 시연하기 전, 강사가 자신의 실습 환경(같은 폴더 신뢰 승인 상태 등)에서 실제로 권한 확인 창이 뜨는지 미리 한 번 실행해본다. 안 뜬다면 시연 멘트를 "창이 뜨면 이렇게, 안 뜨고 바로 결과가 나오면 그것도 정상"으로 조정하고, 뜨는 상황을 보여주고 싶다면 신뢰 승인 전 상태의 새 폴더로 별도 시연을 준비한다.

Slide 9. (실습 중 안내) 하네스 설치 — 다음 시간을 위한 준비

  • 제목: 오늘의 마지막 단계 — 설치
  • 말할 요점: "지금까지는 Claude Code 혼자에게 요청했다. 다음 시간부터는 여러 AI 팀원이 나눠 일하는 팀을 말 한마디로 만든다. 그 도구가 하네스다"라고 연결. 설치 명령 두 줄을 화면에 띄우고 그대로 복붙하도록 안내: /plugin marketplace add revfactory/harness → /plugin install harness@harness-marketplace. 설치에 수십 초 걸릴 수 있고 그동안 화면이 멈춘 듯 보여도 정상이라는 점을 미리 알려준다. /plugin으로 설치 확인하는 법도 함께 보여준다. 빨간 글씨의 에러/실패 메시지가 뜨면 사내망·방화벽으로 GitHub 접근이 막힌 경우일 수 있으니 혼자 재시도하지 말고 바로 TA를 부르라고 명확히 안내한다. 오늘은 설치까지만 — 팀 만들기(구성)는 다음 시간이라는 점을 다시 한번 못 박는다.
  • 강사 노트(사전 점검 필수): 워크숍 시작 전, 교육망에서 실제로 /plugin marketplace add revfactory/harness가 성공하는지(=GitHub·마켓플레이스 접근이 막혀 있지 않은지) 강사가 미리 확인한다. 사내망 차단이 확인되면 대체 네트워크(핫스팟 등) 안내를 준비해둔다.

Slide 10. (실습 중 안내) 자주 막히는 지점 3가지

  • 제목: 이런 화면 만나면
  • 말할 요점: (1) command not found → 설치 문제, TA 호출 (2) 경로 에러(No such file or directory) → 드래그앤드롭으로 다시 (3) 권한 확인 창 → Yes 선택, 안 뜨고 바로 결과가 나와도 정상 (4) 설치 명령이 안 끝나는 것 같다 → 수십 초는 정상, 그래도 안 끝나면 TA 호출 (5) 설치 명령에서 빨간 에러/실패 메시지 → 사내망·방화벽 문제일 수 있으니 혼자 재시도하지 말고 TA 호출. 실습 중간에 다시 한번 화면으로 띄워 상기시킨다.

Slide 11. 공유·정리 (15분)

  • 제목: 오늘 무엇이 신기했나요
  • 말할 요점: 전원이 요약 결과 + 하네스 설치 확인 메시지를 화면에 띄운 상태인지 TA와 함께 확인(성공 기준 체크리스트). 옆 사람과 한 마디씩 소감 공유. "오늘은 검증 없이 결과를 받고 도구만 설치했다 — 다음 시간(first-harness)에는 이 하네스로 실제 AI 팀을 직접 만들고, 그 팀 안에 검증 담당이 있는 것을 눈으로 확인한다"고 다음 모듈을 예고하며 마무리.

Slide 12. 다음 시간 예고

  • 제목: 다음 모듈 — "하네스 구성해줘"
  • 말할 요점: 오늘 켜본 Claude Code와 오늘 설치한 하네스로, 이번엔 "말 한마디로 AI 팀을 만드는" 경험을 한다고 안내. 오늘 만든 작업 폴더와 sample-reviews.txt를 그대로 다시 쓴다고 공지(별도 준비 불필요). "내가 팀을 만들었다"는 경험이 이 교육 전체의 핵심 순간이라고 기대감을 심어준다.
