이 워크시트는 guide.md의 Part 2 실습 중에 채웁니다. 빈칸에 직접 적어 넣으세요. 손으로 인쇄해 채워도, 파일에 그대로 타이핑해도 됩니다.

이름: ___ 팀: ___ 날짜: ____

1. 내 반복 업무

항목 내용
업무명
반복 주기 (예: 매주 월요일, 매분기 초)
현재 방식 (지금은 누가, 어떻게, 얼마나 걸려서 하고 있는지)
왜 힘든가 (반복될 때마다 지치는 지점, 실수가 잦은 지점)

2. 참고한 사례

항목 내용
참고한 사례 문서 (usecases/____.md)
그 사례의 역할 분해에서 내 업무와 비슷한 부분

3. 역할 분해 캔버스 (역할 3~5개)

반드시 역할 중 하나 이상을 "검증 담당"으로 채우세요. 검증 담당은 결과를 만드는 역할과 분리되어야 합니다.

# 역할 이름 받는 것 (입력) 하는 일 넘기는 것 (출력) 검증 담당인가
1 ☐ 예 ☐ 아니오
2 ☐ 예 ☐ 아니오
3 ☐ 예 ☐ 아니오
4 ☐ 예 ☐ 아니오
5 ☐ 예 ☐ 아니오

검증 담당 상세 (반드시 1개 이상 작성)

항목 내용
검증 담당의 역할 번호 (위 표의 #)
무엇을 검증하는가 (예: 인용문이 원문에 실제로 있는지, 개인정보가 남았는지, 근거 없는 추정이 섞였는지)
어떻게 검증하는가 (예: 원문 파일에서 Ctrl/Cmd+F로 검색해 대조)
검증에 걸리는 사람의 확인 시간 (대략)

4. 흐름 확인 (역할이 이어지는가)

각 역할의 "넘기는 것"이 다음 역할의 "받는 것"과 실제로 맞는지 화살표로 확인합니다.

복사해서 쓰세요
1. ______________  →  2. ______________  →  3. ______________  →  4. ______________  →  5. ______________

체크리스트

  • [ ] 역할이 3개 이상 5개 이하다
  • [ ] 검증 담당이 최소 1개 포함되어 있다
  • [ ] 검증 담당이 무엇을·어떻게 검증하는지 구체적으로 적혀 있다
  • [ ] 앞 역할의 출력과 다음 역할의 입력이 서로 맞는다 (끊기는 지점이 없다)
  • [ ] 최종 산출물(마지막 역할의 출력)이 실제로 내 업무에서 필요로 하는 결과물 형식과 같다

5. 과제 실행 계획

항목 내용
다음 실행 예정일 (다음 반복 주기)
실행할 때 첫 번째로 시도해 볼 역할
실행 결과를 저장할 파일/경로
예상되는 막힘 지점 (미리 짐작해보기)

6. 산출물 리뷰용 (1~2주 뒤 작성)

항목 내용
실제로 실행한 날짜
실행 결과 (요약 또는 파일 경로)
검증 담당 단계에서 실제로 잡아낸 문제 (있다면)
실행하며 막혔던 지점
다음에 고치고 싶은 부분
