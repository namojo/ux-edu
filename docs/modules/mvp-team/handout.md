## 0. 오늘 쓰는 핵심 문구 (복붙용)

| 시점 | 문구 |
|------|------|
| 하네스 설치 (처음 한 번만) | `first-contact`에서 이미 완료 — 미설치 시 first-contact 가이드의 하네스 설치 단계 참조 (`/plugin`으로 확인) |
| 입력 파일 준비 | 작업 폴더에 `아이디어.md` — 아이디어가 없으면 함께 제공되는 `sample-idea.md`(사내 회의실 예약 예시)를 `아이디어.md`로 복사해 사용 |
| 팀 구성 (바이브코딩) | `guide.md` 2단계의 "하네스 구성해줘: ..." 전체 문단 그대로 사용 |
| 팀 실행 (트리거) | `guide.md` 3단계 참고 — 2-4에서 하네스가 보여준 실행 방법 문구를 그대로 사용(예시: `프로토타입 만들어줘. 입력은 아이디어.md 파일이야.` — 세션마다 다를 수 있음) |

> **에이전트**: 역할 하나를 맡은 AI 팀원 / **하네스**: 팀을 만들어 주는 도구 / **트리거**: 만들어진 팀을 실행시키는 문구 / **하네스 회고**: 팀 자체를 고쳐 달라는 피드백(진화)

## 1. 자연어 수정 요청 문구 — 카테고리별 예시

**같은 대화(팀을 실행한 세션)에 이어서 그대로 입력**하면 됩니다. `{ }` 부분만 내 화면·요소로 바꾸세요.

### 화면·요소 추가
- `{화면 이름}에 {추가하고 싶은 요소}를 추가해줘`
- 예: "주문 완료 화면에 예상 픽업 시간(예: 5분 뒤)을 표시해줘"
- 예: "홈 화면 상단에 공지 배너를 추가해줘"

### 문구·카피 변경
- `{화면 이름}의 '{현재 문구}'를 '{바꿀 문구}'로 바꿔줘`
- 예: "완료 화면의 '주문 완료'를 '접수됐어요!'로 바꿔줘"
- 예: "버튼 이름을 '다음' 대신 '이 시간으로 예약'처럼 행동이 드러나게 바꿔줘"

### 스타일·톤 변경
- 예: "전체 버튼 색을 한 가지로 통일해줘"
- 예: "홈 추천 카드에 사진 느낌의 색 배경을 넣어줘"
- 예: "전체 톤을 더 차분하고 신뢰감 있게 바꿔줘"

### 화면 흐름 변경
- 예: "환영 화면을 2단계 소개(스와이프)로 늘려줘"
- 예: "완료 화면에 뒤로가기 버튼을 추가해서 막다른 길이 없게 해줘"

### 반응형·기기
- 예: "데스크톱 기준으로만 나와 있는데, 모바일 세로 화면(폭 375px 정도) 기준으로 바꿔줘"

### 접근성
- 예: "이미지 자리에 대체 텍스트(alt)를 추가해줘"
- 예: "버튼 글자색과 배경색의 대비를 더 뚜렷하게 해줘"

## 2. 수정 요청 vs 하네스 회고 — 뭘 쓸지 헷갈릴 때

| 질문 | "예"면 → |
|------|----------|
| 이번 화면 딱 한 번만 고치면 끝인가? | **자연어 수정 요청** (위 1번 문구) |
| 다음에 다른 아이디어로 팀을 또 돌려도 매번 반복해서 요구하게 될까? | **하네스 회고** (팀에 심기) |

### 하네스 회고 문구 템플릿
```
하네스 회고: {팀원 이름 또는 역할}이(가) {지금 놓치고 있는 것}을 자주 놓쳐.
{앞으로 항상 확인/포함해야 할 것}을 반드시 하도록 {팀원}을 개선해줘.
```

**예시**
```
하네스 회고: 검수자가 시각 디자인 지적은 잘하는데 "흐름이 도중에 막히는지"는 자주 놓쳐.
검수 항목에 "모든 버튼이 실제로 다음 화면으로 연결되는지" 확인을 반드시 넣도록 검수자를 개선해줘.
```
```
하네스 회고: 프로토타입이 데스크톱 기준으로만 나와. 우리 사용성 테스트는 모바일로 하니까,
구현자가 기본으로 모바일 세로 화면(폭 375px 정도) 기준으로 만들도록 바꿔줘.
```

> 하네스 회고는 팀의 정의(에이전트/스킬 파일)를 고치는 것이라, 효과는 **다음 실행부터** 보입니다. 지금 화면이 바로 안 바뀌어도 정상입니다.

## 3. 실행 전 마지막 확인

- [ ] 수정 요청은 **팀을 실행한 것과 같은 대화(세션)**에 이어서 입력했다
- [ ] 수정 후 브라우저에서 **새로고침**해 반영을 확인했다
- [ ] AI가 채운 예시 데이터(이름·가격·후기 등)는 **가짜**임을 잊지 않았다 — 사용성 테스트 전 실제 데이터로 교체하거나 "예시 데이터"임을 표시
