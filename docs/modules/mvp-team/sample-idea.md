## 사내 회의실 예약 MVP

빈 회의실을 찾아 예약하는 흐름을 3분 안에 끝낼 수 있는지 검증하려는 시제품입니다.

### 화면 흐름

- **화면1 (홈 / 지금 빈 회의실)**
  - 상단: 오늘 날짜와 현재 시각, "지금 비어 있는 회의실" 개수
  - 목록: 회의실 카드 4~5개 (회의실 이름, 수용 인원, 층, 지금부터 몇 분간 비어 있는지)
  - 필터 칩: `4인 이하` `5~8인` `9인 이상` `화면 있음`
  - 카드를 누르면 화면2로 이동
- **화면2 (회의실 상세 / 시간 선택)**
  - 회의실 사진 자리(회색 박스로 대체), 이름, 수용 인원, 비품(모니터·화이트보드·전화)
  - 시간 선택: 30분 단위 시간 칩 (이미 예약된 시간은 선택 불가 상태로 표시)
  - 회의 제목 입력칸, 참석자 수 선택
  - `예약 확인으로` 버튼 → 화면3
- **화면3 (예약 확인)**
  - 예약 요약: 회의실 · 날짜 · 시간 · 참석자 수 · 회의 제목
  - 안내 문구: 시작 10분 전 알림이 간다는 안내
  - `수정하기`(화면2로 돌아감) / `예약 확정` 버튼 → 화면4
- **화면4 (예약 완료)**
  - 완료 메시지, 예약 번호, 회의실 위치(층·방향) 안내
  - `캘린더에 추가`(눌리기만 하는 가짜 버튼), `홈으로 돌아가기` → 화면1

### 목표 사용자

회의 시작 직전에 급히 회의실을 잡아야 하는 사내 직원. 대부분 모바일에서, 서 있는 상태로 사용합니다.

### 톤

깔끔하고 업무적. 장식보다 정보 우선. 지금 예약 가능한지 여부가 한눈에 보이는 것이 가장 중요합니다.

### 이번 시제품으로 검증하고 싶은 것

1. 홈 화면만 보고 "지금 쓸 수 있는 회의실"을 3초 안에 판단할 수 있는가
2. 시간 선택에서 이미 예약된 시간과 가능한 시간을 헷갈리지 않는가
3. 예약 확인 화면에서 되돌아가 수정하는 흐름이 막히지 않는가
