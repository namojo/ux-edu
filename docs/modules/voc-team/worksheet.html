워크시트 — 내 VoC 준비 체크리스트

voc-team 모듈 실습을 시작하기 전, 그리고 실습 중간에 채우는 시트입니다. 2단계(팀 구성 프롬프트)를 쓸 때 이 시트 내용을 그대로 참고하면 중괄호 채우기가 쉬워집니다.

이름: __ / 서비스·프로젝트명: __ / 날짜: ____

1. 데이터 출처

가져온(또는 대체 데이터를 쓰는) VoC 데이터가 어디서 왔는지 표시하세요. 여러 개면 모두 체크합니다.

  • [ ] 앱스토어 / 플레이스토어 리뷰
  • [ ] CS 티켓(고객센터 문의·상담 기록)
  • [ ] 설문 자유응답
  • [ ] 소셜/커뮤니티 댓글
  • [ ] 기타: ____
  • [ ] 함께 제공되는 대체 데이터 사용 (자기 데이터 미지참)

파일명(들): ____________

2. 데이터 기간

  • 데이터 수집 기간: _ 년 _ 월 _ 일 ~ _ 년 _ 월 _ 일
  • 대략 건수: ____ 건
  • 비교할 이전 리포트가 있는가? [ ] 있음 (파일명: __) [ ] 없음 — 오늘 결과가 첫 기준선

3. 익명화 처리

  • [ ] 이름을 지우거나 가렸다
  • [ ] 전화번호·이메일을 지우거나 가렸다
  • [ ] 주소·소속 등 간접 식별 정보를 확인했다
  • [ ] 아직 익명화하지 않음 — 실습 전에 처리 필요
  • 비고(어떤 방식으로 처리했는지): ____________

개인정보가 남아있는 상태로 실습을 진행하지 마세요. 확실치 않으면 사내 개인정보 처리 가이드라인을 먼저 확인하거나, 사내 헬프 채널에 문의하세요.

4. 별점(평점) 유무

  • [ ] 별점 열이 있다 → 2단계 프롬프트에 "별점도 함께 참고해서 감정을 판정해줘" 문장을 넣는다
  • [ ] 별점 열이 없다 → 2단계 프롬프트에 "별점 데이터는 없어서 텍스트 내용으로만 감정을 판정해줘" 문장을 넣는다

5. 채널 구성 메모 (선택)

파일을 채널별로 나눠 넣었다면 간단히 적어 두세요 — 가이드 2단계 프롬프트의 {reviews.txt 등 준비한 파일명} 슬롯에 파일명을 여러 개 나열할 때 씁니다.

파일명 채널 대략 건수

6. 2단계 프롬프트에 넣을 내 정보 미리 적어보기

가이드 2단계의 { } 중괄호를 채우기 전에, 여기서 먼저 문장으로 정리해 보세요.

  • 서비스명: ____________
  • 데이터 종류 문장(위 1번 참고 — 예: "앱 리뷰와 CS 티켓", "설문 자유응답"): ____________
  • 입력 파일명: ____________
  • 별점 관련 문장 (위 4번 참고): ____________
  • 전 분기 비교 문장 (위 2번 참고, 없으면 이 줄은 비워두고 프롬프트에서 뺀다): ____________

이 시트를 다 채웠다면 가이드 2단계로 넘어가 하네스 구성 프롬프트를 완성하세요.
