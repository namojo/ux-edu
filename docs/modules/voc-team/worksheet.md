## 3. 익명화 처리

- [ ] 이름을 지우거나 가렸다
- [ ] 전화번호·이메일을 지우거나 가렸다
- [ ] 주소·소속 등 간접 식별 정보를 확인했다
- [ ] 아직 익명화하지 않음 — 실습 전에 처리 필요
- 비고(어떤 방식으로 처리했는지): ________________________________________________

> 개인정보가 남아있는 상태로 실습을 진행하지 마세요. 확실치 않으면 사내 개인정보 처리 가이드라인을 먼저 확인하거나, 사내 헬프 채널에 문의하세요.
>
> 이 항목은 **자기 데이터**를 쓸 때의 기준입니다. 대체 데이터를 쓴다면 이 표는 "해당 없음"으로 두세요 — 대체 데이터에는 검증 담당의 마스킹 동작을 확인하기 위한 **가상** 개인정보가 일부 일부러 들어 있고, 그걸 걸러내는 것이 4단계 실습 내용입니다.

## 4. 별점(평점) 유무

- [ ] 별점 열이 있다 → 2단계 프롬프트에 "별점도 함께 참고해서 감정을 판정해줘" 문장을 넣는다
- [ ] 별점 열이 없다 → 2단계 프롬프트에 "별점 데이터는 없어서 텍스트 내용으로만 감정을 판정해줘" 문장을 넣는다
- [ ] 파일마다 다르다(대체 데이터가 이 경우) → 어떤 파일에 별점이 있는지 프롬프트에 명시한다. 예: "앱 리뷰에는 별점이 있으니 함께 참고하고, CS 티켓은 별점이 없으니 텍스트 내용으로만 판정해줘"
