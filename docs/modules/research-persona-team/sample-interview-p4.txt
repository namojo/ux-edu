# 대체 실습 데이터 — 사용자 인터뷰 녹취 발췌 (P4)
# 가상의 모바일 커머스 앱 "빈살롱 스토어"의 결제·이탈 경험 인터뷰입니다. 교육용으로 만든 가상 데이터이며 실제 참가자가 아닙니다.
# 참가자: P4 / 50대 초반 / 자영업 / 월 2~3회 구매, PC와 모바일 병행 / 인터뷰 2026-06-15 / 진행자 1명

[진행자] 보통 어떤 기기로 구매하시나요?
[P4] 고르는 건 휴대폰으로 하고, 결제는 컴퓨터로 하는 편이에요. 화면이 커야 글씨가 보이니까요.
[P4] 휴대폰에서는 상품 설명 글씨가 너무 작아요. 확대하면 표가 잘려서 위아래로 계속 움직여야 합니다.
[진행자] 그러면 기기를 옮기는 과정은 어떠세요?
[P4] 휴대폰에서 담아두고 컴퓨터에서 열면 장바구니가 그대로 있어서 그건 편해요.
[P4] 다만 컴퓨터에서는 로그인을 또 해야 해요. 인증번호를 휴대폰으로 받아서 컴퓨터에 옮겨 적습니다. 번거롭죠.
[진행자] 물건을 고를 때 무엇을 확인하시나요?
[P4] 리뷰를 꼼꼼히 읽어요. 특히 나쁜 리뷰부터 봅니다. 나쁜 이유가 내가 신경 쓰는 부분이면 안 사요.
[P4] 그리고 교환·반품 규정을 봐요. 사업에 쓰는 물건도 있어서 잘못 사면 손해가 큽니다.
[P4] 반품 규정이 어디 있는지 매번 찾아야 해요. 상품마다 위치가 다른 것 같아요.
[진행자] 결제 단계에서 어려운 점이 있나요?
[P4] 간편결제라는 게 여러 개 있는데 뭐가 뭔지 모르겠어요. 저는 그냥 카드번호를 직접 넣습니다.
[P4] 카드번호 넣는 칸이 작아서 잘못 누르면 처음부터 다시 입력해야 해요. 한 번 틀리면 짜증이 납니다.
[P4] 그리고 결제 마지막에 금액이 달라지는 건 저도 겪었어요. 배송비 때문에요. 미리 알려주면 좋겠습니다.
[진행자] 구매를 포기한 적이 있나요?
[P4] 있어요. 결제 창에서 인증이 안 넘어가서 30분 붙잡고 있다가 전화로 주문했습니다. 그 가게는 전화가 되니까요.
[P4] 인증 실패 이유를 안 알려줘요. 그냥 다시 시도하라고만 나와요. 뭘 고쳐야 할지 모르겠더라고요.
[진행자] 개선되면 좋겠다고 생각하는 것은 무엇인가요?
[P4] 글씨 크기요. 설정에서 크게 해도 상품 설명 이미지 안 글씨는 그대로예요. 그건 안 커집니다.
[P4] 그리고 결제 단계 수를 줄여주세요. 화면이 계속 넘어가면 지금 어디까지 온 건지 모르겠어요.
