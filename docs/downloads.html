실습 데이터 — 자기 데이터가 없어도 됩니다

L1 두 모듈은 아래 공용 샘플(리뷰 20건)로 진행합니다. L2 이후 모듈은 자기 서비스의 실제 데이터로 하는 것이 원칙입니다(그래야 산출물이 실무로 이어집니다). 못 가져왔더라도 실습이 멈추지 않도록, 모듈마다 같은 흐름을 끝까지 돌릴 수 있는 대체 데이터를 함께 배포합니다. 아래 파일은 전부 가상으로 만든 교육용 데이터이며 실제 고객·참가자 데이터가 아닙니다.

받은 파일, 어떻게 쓰나요

  • .md (마크다운) — 메모장·VS Code로 열립니다. Claude Code 대화창에 파일을 끌어다 놓거나 guide.md 읽어줘처럼 말하면 AI가 바로 내용을 읽습니다.
  • .txt (실습 데이터) — 실습에서 AI에게 읽히는 연습용 데이터입니다. 작업 폴더에 넣고 sample-reviews.txt 읽고 요약해줘처럼 파일명을 말하면 됩니다. L2 이후 모듈의 대체 데이터는 위 표에서 모듈별로 확인하세요.
  • 워크시트 — 브라우저에서 열어 🖨 인쇄하기로 종이에 뽑아 쓰는 것도 됩니다.
