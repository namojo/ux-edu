첫 실습 치트시트

터미널 열기 · 폴더 이동(cd) · 권한 확인 창 대응 — first-contact 모듈 · 책상에 두고 보세요

1 오늘의 순서
폴더 만들기 → 터미널 열기 → claude 입력 → 파일 읽혀 요약 요청 → 권한 확인 창에서 Yes → 결과 확인 → 후속 요청으로 다듬기
2 터미널 여는 두 가지 방법
방법 B · cd로 이동하기 (기본 추천)
  1. 터미널 실행 (Cmd+Space → "터미널")
  2. cd 입력 후 띄어쓰기
  3. 작업 폴더를 창 위로 드래그앤드롭 → Enter
방법 A · 폴더에서 바로 열기 (보조)
  1. 작업 폴더 우클릭
  2. "폴더에서 새 터미널 열기" 클릭
  3. 이 메뉴는 기본값으로 없을 수 있음 — 없으면 바로 방법 B
3 잘 들어왔는지 확인 & 실행
폴더 안 파일 목록 보기
ls
→ sample-reviews.txt가 보이면 OK
Claude Code 켜기
claude
→ 화면이 바뀌면 대화창 시작
4 오늘 쓸 프롬프트 (그대로 복붙)
sample-reviews.txt 파일을 읽고 무슨 내용인지 3줄로 요약해줘.
방금 요약을 표로 다시 보여줘.
5 claude 처음 켤 때 나오는 화면들 (순서대로)
① 로그인/계정 화면
기본값으로 넘길 수 없는 실제 인증 화면입니다. 사전 로그인이 안 됐다면 혼자 진행하지 말고 바로 손을 들어 강사를 부르세요.
② 폴더 신뢰 확인 (Do you trust the files...?)
처음 보는 폴더에서 한 번 묻습니다. 우리가 만든 연습 폴더이므로 Yes, proceed를 선택하세요.
③ 파일 접근 권한 확인 창도 정상입니다. Claude Code가 내 파일을 읽거나 만지기 전에 매번 "해도 되는지" 사람에게 확인받는 안전장치입니다. 지금은 우리 연습용 폴더이므로 1. Yes를 선택하고 Enter를 누르면 됩니다.
  • 화면에 Allow? 또는 허용 여부를 묻는 선택지가 보인다 → 정상, 놀라지 않는다
  • 1. Yes 선택 후 Enter
  • 선택지가 사라지고 다시 작업이 진행되면 성공
6 막히면 이렇게
command not found
설치가 안 됐거나 터미널 재시작이 필요한 경우. 손을 들어 TA를 부르세요.
No such file or directory
경로가 잘못 입력된 경우. 줄을 지우고 폴더를 다시 드래그앤드롭하세요.
