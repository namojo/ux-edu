# 슬라이드 개요 (강사용) — AI에게 내 파일을 맡기는 첫 경험

모듈: `first-contact` / L1 / 90분 / 도입·시연 30분 — 실습 45분 — 공유·정리 15분
완성 슬라이드가 필요하면 이 개요를 바탕으로 pptx 스킬로 제작 요청하세요. 아래는 슬라이드별 제목 + 강사가 말할 요점입니다.

---

### Slide 1. 표지
- **제목**: AI에게 내 파일을 맡기는 첫 경험
- **말할 요점**: 오늘은 개념 수업이 아니라 직접 손으로 해보는 시간이라고 못 박는다. "90분 뒤 여러분 노트북 화면에는 여러분이 직접 받은 AI 요약이 떠 있을 것"이라고 목표를 먼저 던진다.

### Slide 2. 오늘 배우는 것 (학습 목표)
- **제목**: 오늘의 목표
- **말할 요점**: (1) 터미널 열기 (2) 작업 폴더로 이동해 `claude` 켜기 (3) 폴더 안 파일을 읽혀 결과 받기 — 이 세 가지를 "혼자서" 끝까지 해내는 것이 목표. 지식 습득이 아니라 손에 익히는 것임을 강조.

### Slide 3. 왜 "폴더"부터 만드나
- **제목**: Claude Code는 지금 있는 폴더만 본다
- **말할 요점**: Claude Code는 컴퓨터 전체를 뒤지는 게 아니라, 터미널이 열려 있는 그 폴더 안의 파일만 읽고 쓴다는 개념을 짧게 그림으로 설명(폴더 아이콘 + 그 안의 파일들). 그래서 "이번 작업용 폴더"를 매번 먼저 만드는 습관을 들인다고 연결.

### Slide 4. (시연) 폴더 만들기 → 터미널 열기
- **제목**: 같이 해봅시다 — 1, 2단계
- **말할 요점**: 화면 미러링으로 실제 진행. 바탕화면 우클릭 → 새 폴더 → 이름 정하기 → 샘플 파일 넣기 → **방법 B를 기본 시연**: 터미널 실행(Cmd+Space → "터미널") → `cd ` 입력 후 폴더를 창 위로 드래그앤드롭 → Enter. 이 순서를 천천히, 마우스 움직임까지 보이며 시연. 방법 A(폴더 우클릭 "폴더에서 새 터미널 열기")는 이 메뉴가 기본값으로 꺼져 있는 Mac이 많으므로 "메뉴가 이미 켜져 있는 분만 쓰는 지름길"로 보조 언급만 한다 — 라이브 시연을 방법 A로 하면 메뉴가 없어서 막힌다. Windows 사용자는 별도 안내(가이드 참고 페이지) 언급.

### Slide 5. (시연) `claude` 켜기
- **제목**: 같이 해봅시다 — 3단계
- **말할 요점**: 터미널에 `claude` 입력 → Enter → 화면이 바뀌는 순간을 보여준다. 이때 **로그인/계정 화면**과 **"Do you trust the files in this folder?" 신뢰 확인 화면**이 권한 확인 창(Slide 7)보다 먼저 나타날 수 있음을 미리 스크린샷으로 보여주고 순서를 짚어준다: (1) 로그인 화면 — 사전 인증이 안 된 사람은 여기서 멈추고 손을 들도록 안내(도입 30분에 로그인까지 끝냈는지 재확인), (2) 신뢰 확인 화면 — 우리가 만든 연습 폴더이니 "Yes, proceed"를 고르면 된다고 시연. 이 두 화면을 미리 보여주지 않으면 실습 중 가장 먼저, 가장 조용히 막히는 지점이 된다. 이후 언어·테마 등 초기 설정 화면이 있다면 그 자리에서 같이 넘긴다.

### Slide 6. 프롬프트란 무엇인가
- **제목**: 프롬프트 = AI에게 보내는 요청 문장
- **말할 요점**: 어려운 코드가 아니라 그냥 한국어 문장을 치는 것뿐이라는 점을 강조. 오늘 쓸 첫 문장을 슬라이드에 크게 띄워서 다 같이 읽는다: "sample-reviews.txt 파일을 읽고 무슨 내용인지 3줄로 요약해줘."

### Slide 7. (시연) 권한 확인 창 — 오늘의 핵심 장면
- **제목**: 이 창이 뜨면 정상입니다
- **말할 요점**: 권한 확인 창 스크린샷을 미리 준비해 띄운다. "AI가 내 파일을 함부로 만지지 않도록 매번 물어보는 안전장치"라고 명확히 설명 — 이걸 미리 보여주지 않으면 실습 중 가장 많이 이탈하는 지점이 된다. `Yes`를 선택해 진행하는 것까지 시연.

### Slide 8. (시연) 결과 받기 + 후속 요청
- **제목**: 대화가 이어진다
- **말할 요점**: 요약 결과를 받은 뒤 "방금 요약을 표로 다시 보여줘"를 이어 입력해 결과가 바뀌는 것을 보여준다. "한 번 던지고 끝이 아니라, 이어서 다듬을 수 있다"는 이 모듈의 핵심 체감 포인트를 여기서 짚는다.

### Slide 9. 이제 여러분 차례 — 실습 안내 (45분)
- **제목**: 실습 시작
- **말할 요점**: 가이드(`guide.md`) 1~6단계를 각자 속도로 진행하도록 안내. TA가 자리를 돌며 권한 창·경로 문제를 즉시 잡아준다고 공지. 막히면 손을 들라고 명확히 안내(당황해서 조용히 포기하는 사람이 없도록).

### Slide 10. (실습 중 안내) 자주 막히는 지점 3가지
- **제목**: 이런 화면 만나면
- **말할 요점**: (1) `command not found` → 설치 문제, TA 호출 (2) 경로 에러(No such file or directory) → 드래그앤드롭으로 다시 (3) 권한 확인 창 → `Yes` 선택. 실습 중간에 다시 한번 화면으로 띄워 상기시킨다.

### Slide 11. 공유·정리 (15분)
- **제목**: 오늘 무엇이 신기했나요
- **말할 요점**: 전원이 요약 결과를 화면에 띄운 상태인지 TA와 함께 확인(성공 기준 체크리스트). 옆 사람과 한 마디씩 소감 공유. "오늘은 검증 없이 결과를 받기만 했다 — 다음 시간(`prompt-and-verify`)에는 이 결과를 의심하고 확인하는 법을 배운다"고 다음 모듈을 예고하며 마무리.

### Slide 12. 다음 시간 예고
- **제목**: 다음 모듈 — 좋은 요청과 결과 검증
- **말할 요점**: 오늘 켜본 Claude Code로 이번엔 "더 구체적으로 요청하는 법"과 "AI가 지어낸 내용을 걸러내는 법"을 배운다고 안내. 오늘 만든 작업 폴더와 `sample-reviews.txt`를 그대로 다시 쓴다고 공지(별도 준비 불필요).
