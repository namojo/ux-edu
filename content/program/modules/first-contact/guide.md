# 실습 가이드 — AI에게 내 파일을 맡기는 첫 경험

| 항목 | 내용 |
|------|------|
| 레벨 / 시간 | L1 / 90분 (도입·시연 30분 — 실습 45분 — 공유·정리 15분) |
| 선수 조건 | 없음. 단, **Claude Code가 노트북에 설치되어 있어야** 합니다. |
| 준비물 | 노트북, `sample-reviews.txt`(강사가 나눠주는 리뷰 20건 샘플 파일) |
| 오늘의 목표 | 터미널을 열고 → 작업 폴더로 이동해 `claude`를 켜고 → 폴더 안 파일을 읽혀 → 첫 결과를 받는다. 이 전 과정을 **혼자서** 해낸다. |

> 이 문서에서 "Claude Code"는 우리가 오늘 쓸 AI 도구의 이름입니다. 터미널(명령어를 입력하는 검은/흰 창)에서 `claude`라는 명령어로 켭니다. 앞으로 이 자료에서는 도구 이름은 "Claude Code", 켜는 명령어는 `claude`로 통일해서 씁니다.

---

## 0. 시작 전 확인 (강사가 화면으로 함께 진행, 5분)

터미널을 처음 보는 분도 있을 수 있으니, 이 확인은 각자 먼저 시도하지 말고 **강사가 화면을 공유해 함께** 진행합니다. (터미널을 여는 자세한 방법은 2단계에서 다시 다룹니다.)

☐ 노트북에 Claude Code가 설치되어 있다 (터미널에 `claude`라고 쳤을 때 뭔가 반응이 있으면 설치된 것)
☐ **`claude` 실행 시 로그인/계정 인증까지 이미 끝나 있다** (도입 설치 과정에서 계정 로그인까지 완료했는지 강사가 이름을 불러 확인합니다)
☐ 안 되어 있다면 손을 들어주세요 — 도입 30분 동안 강사·TA와 함께 설치·로그인까지 마칩니다.
☐ 강사가 나눠준 `sample-reviews.txt` 파일을 다운로드/전달받았다 (USB, 메신저 파일 전송, 또는 사내 공유 폴더)

> 💡 **이렇게 나오면 정상입니다: 터미널에 `claude`를 쳤는데 "command not found"가 뜬다**
> → 아직 설치가 안 됐거나, 터미널을 재시작해야 인식되는 경우입니다. 조용히 손을 들어주세요. 혼자 이것저것 눌러보지 않아도 됩니다.

---

## 1단계. 바탕화면에 작업 폴더 만들기 (강사 시연 → 다 함께)

**"작업 폴더"**는 오늘 우리가 쓸 파일들을 모아두는 전용 폴더입니다. Claude Code는 **지금 열려 있는 폴더 안의 파일만** 읽고 씁니다. 그래서 매번 "이번 작업용 폴더"를 하나 만들고 그 안에서 시작하는 습관을 들입니다.

1. 바탕화면(Desktop)에서 마우스 우클릭 → **새로운 폴더(New Folder)**
2. 폴더 이름을 알아보기 쉽게 정합니다. 오늘은 `first-contact-실습` 으로 통일하겠습니다.
3. 강사가 나눠준 `sample-reviews.txt` 파일을 이 폴더 **안으로** 옮겨 넣습니다(드래그앤드롭 또는 복사-붙여넣기).

> 💡 **이렇게 나오면 정상입니다: 파일이 다운로드 폴더에 있는데 어떻게 옮기는지 모르겠다**
> → Finder(파일 탐색기) 창을 하나 더 열어(Cmd+N) 다운로드 폴더와 바탕화면 폴더를 나란히 띄우고 파일을 끌어다 놓으면 됩니다. TA에게 요청해도 됩니다.

---

## 2단계. 터미널 열기 (강사 시연 → 다 함께)

터미널은 마우스 대신 **글자로 명령을 입력해 컴퓨터를 조작하는 창**입니다. 오늘은 딱 두 가지 방법 중 편한 것으로 엽니다.

**방법 B — 터미널을 먼저 켜고 `cd`로 이동하기 (기본 추천)**
1. Spotlight(Cmd+Space)에서 "터미널"이라고 검색해 실행
2. `cd `(cd 뒤에 띄어쓰기 한 번) 까지만 입력한 상태에서, **바탕화면의 `first-contact-실습` 폴더를 터미널 창 위로 드래그앤드롭**합니다. 폴더 경로가 자동으로 입력됩니다.
3. Enter를 누릅니다.

**방법 A — 폴더에서 바로 열기 (메뉴가 이미 켜져 있는 경우에만)**
1. 방금 만든 `first-contact-실습` 폴더를 마우스 우클릭
2. 메뉴에서 **"폴더에서 새 터미널 열기(New Terminal at Folder)"** 클릭
   - 안 보이면 메뉴 맨 아래 **"더 보기(More)"** 안에 있을 수 있습니다.
3. 검은/흰 창(터미널)이 뜨면, 이미 우리 작업 폴더 안에 들어와 있는 상태입니다.

> 💡 **이렇게 나오면 정상입니다: 우클릭 메뉴에 "폴더에서 새 터미널 열기"가 아예 안 보인다**
> → macOS는 이 메뉴가 **기본값으로 꺼져 있는 경우가 더 많습니다.** 설정(시스템 설정 > 키보드 > 단축키 > 서비스)에서 따로 켜야 보이므로, 안 보이는 게 오히려 정상입니다. 시간 끌지 말고 바로 위 **방법 B**로 진행하세요.

> 💡 **이렇게 나오면 정상입니다: `cd` 이후 Enter를 눌렀는데 에러 문구(빨간 글씨, "No such file or directory")가 뜬다**
> → 경로에 오타가 있거나 띄어쓰기가 잘못 들어간 경우입니다. 방금 입력한 줄을 지우고(백스페이스), 폴더를 다시 드래그앤드롭해서 새로 입력하세요. 직접 타이핑보다 드래그앤드롭이 훨씬 안전합니다.

**내가 올바른 폴더 안에 들어왔는지 확인하는 법**: 터미널에 `ls`를 입력하고 Enter. `sample-reviews.txt`가 목록에 보이면 성공입니다.

```
ls
```

> 💡 **이렇게 나오면 정상입니다: `ls`를 쳤는데 아무 파일도 안 보인다 (또는 `sample-reviews.txt`가 없다)**
> → 아직 다른 폴더에 있는 상태입니다. 1단계에서 파일을 정말 `first-contact-실습` 폴더 "안에" 넣었는지 Finder에서 다시 확인하고, 2단계를 처음부터 다시 하세요.

---

## 3단계. Claude Code 켜기 (강사 시연 → 다 함께)

터미널에 아래와 같이 입력하고 Enter를 누릅니다.

```
claude
```

몇 초 기다리면 화면이 바뀌면서 Claude Code 대화창이 나타납니다. 이제부터 여기에 원하는 것을 **한국어 문장으로** 입력하면 됩니다.

`claude`를 처음 켤 때는 아래 화면들이 **순서대로** 나타날 수 있습니다. 당황하지 말고 하나씩 넘어가세요.

> 💡 **이렇게 나오면 정상입니다: 로그인/계정 화면이 나온다**
> → 사전에 계정 인증이 끝나지 않은 상태입니다. **이 화면은 기본값으로 그냥 넘길 수 없습니다** — 실제 계정 로그인이 필요한 화면입니다. 혼자 아이디·비밀번호를 넣거나 이것저것 눌러보지 말고, **바로 손을 들어 강사를 불러주세요.** (0단계에서 설치 시 로그인까지 끝냈어야 하는 부분입니다.)

> 💡 **이렇게 나오면 정상입니다: "Do you trust the files in this folder?"(이 폴더의 파일을 신뢰합니까?) 같은 신뢰 확인 화면이 나온다**
> → Claude Code가 처음 보는 폴더에서 실행될 때 한 번 묻는 화면입니다. 지금 폴더는 오늘 우리가 직접 만든 연습용 폴더이므로, **"Yes, proceed"(예, 진행합니다)** 를 선택하고 Enter를 누르면 됩니다.

> 💡 **이렇게 나오면 정상입니다: 언어·테마 등을 묻는 초기 설정 화면이 나온다**
> → 처음 실행 시 한 번만 나오는 화면입니다. 방향키나 숫자로 항목을 고르고 Enter로 다음으로 넘어가면 됩니다(기본값 그대로 진행해도 무방).

---

## 4단계. 첫 프롬프트 — 파일을 읽혀서 요약받기 (실습, 다 함께)

**"프롬프트"**란 우리가 AI에게 입력하는 요청 문장을 말합니다. 오늘부터 이 자료에서는 이 말을 그대로 씁니다.

Claude Code 대화창에 아래 문장을 그대로 입력하고 Enter를 누르세요. (복사-붙여넣기 가능)

```
sample-reviews.txt 파일을 읽고 무슨 내용인지 3줄로 요약해줘.
```

입력하고 나면 화면에 파일을 읽는 과정이 잠깐 보이다가, 이어서 요약 결과가 나타납니다.

> 💡 **이렇게 나오면 정상입니다: 파일 접근 권한을 확인하는 창(Allow? / 허용하시겠습니까?)이 뜬다**
> → **오늘 가장 많이 만나는 화면입니다.** Claude Code는 내 컴퓨터의 파일을 읽거나 실행하기 전에 "정말 이 폴더의 이 작업을 해도 되는지" 매번 사람에게 확인을 받습니다. 이유: AI가 마음대로 파일을 손대지 않도록 하는 안전장치입니다.
> - 화면에 보통 `1. Yes` / `2. Yes, and don't ask again` / `3. No` 같은 선택지가 나옵니다.
> - 지금은 우리가 만든 연습용 폴더이므로 **`1. Yes`** (한 번만 허용)를 선택하고 Enter를 누르면 됩니다.
> - 이 창이 뜨는 것 자체가 **정상이고 오히려 안전하게 작동하고 있다는 신호**입니다. 놀라지 않아도 됩니다.

> 💡 **이렇게 나오면 정상입니다: 결과가 영어로 나온다**
> → 드물게 발생합니다. 당황하지 말고 `한국어로 다시 대답해줘`라고 이어서 입력하면 됩니다. (다음 모듈 `prompt-and-verify`에서 이런 후속 요청을 더 자세히 다룹니다.)

> 💡 **이렇게 나오면 정상입니다: 오타를 냈다 / Enter를 잘못 눌렀다**
> → 대화창은 채팅과 같아서 잘못 보내도 괜찮습니다. 다음 줄에 다시 정확한 문장을 입력해 보내면 됩니다. 되돌리기 걱정 없이 편하게 입력하세요.

---

## 5단계. 결과 확인 (실습, 다 함께)

화면에 뜬 요약을 소리 내어 읽어봅니다. 3줄로 요약이 됐는지, 리뷰 20건의 전체적인 느낌(배달 지연, 결제 오류, 만족 후기 등)이 잘 담겼는지 눈으로 확인합니다.

> 지금 단계에서는 **결과가 완벽히 정확한지 검증하지 않습니다.** "AI가 파일을 읽고 뭔가 그럴듯한 결과를 돌려준다"는 감각을 익히는 것이 오늘의 목표입니다. 결과를 의심하고 검증하는 방법은 다음 모듈 `prompt-and-verify`에서 배웁니다.

## 6단계. 후속 요청 — 대화가 이어진다는 것 체감하기 (실습, 다 함께)

Claude Code는 이전 대화 내용을 기억한 채로 이어서 대화할 수 있습니다. 방금 받은 요약을 다른 형태로 다시 요청해봅니다.

```
방금 요약을 표로 다시 보여줘.
```

방금 받은 3줄 요약이 이번엔 표(항목/내용 같은 형태) 모양으로 다시 정리되어 나오는 것을 확인합니다.

> 💡 **이렇게 나오면 정상입니다: "방금"이 무엇을 가리키는지 못 알아듣는 것 같다**
> → 아주 드물게, 이전 요청과 너무 다른 새 대화처럼 반응할 때가 있습니다. 이럴 땐 `방금 sample-reviews.txt 요약해준 내용을 표로 다시 보여줘`처럼 무엇을 가리키는지 조금 더 구체적으로 적어주면 됩니다.

이 단계가 오늘 자료의 핵심 체험입니다: **한 번 던지고 끝나는 게 아니라, 이어서 다듬을 수 있다**는 감각을 몸에 익히는 것.

## 7단계. (여유 시간에) 한 번 더 해보기 — 자유 실습

시간이 남으면 아래 중 하나를 자유롭게 시도해보세요. 정답은 없습니다.

- `별점이 높은 리뷰와 낮은 리뷰를 나눠서 각각 몇 개인지 세어줘.`
- `이 리뷰들 중에 배달 관련 불만만 골라줘.`
- `방금 결과를 조금 더 짧게, 한 문장으로 줄여줘.`

## 마무리 체크 (성공 기준)

오늘 모듈은 아래를 **모든 학습자가** 화면에 띄운 상태로 마칩니다. TA가 자리를 돌며 확인합니다.

☐ 내 노트북에서 `claude`를 켰다
☐ `sample-reviews.txt` 파일을 읽혀 요약 결과를 최소 1회 받았다
☐ 권한 확인 창이 떴을 때 당황하지 않고 대응했다 (또는 앞으로 어떻게 대응할지 안다)
☐ 후속 요청(표로 재구성)으로 대화가 이어지는 것을 확인했다

이 화면을 그대로 두고 공유·정리 시간에 옆 사람과 "무엇이 신기했는지" 한 마디씩 나눕니다.

## 참고 — Windows 사용자라면

이 실습은 macOS Finder 기준으로 작성했습니다. Windows에서는 아래로 대체하세요.

- 폴더 우클릭 → **"터미널에서 열기"** (없으면 폴더 안에서 주소 표시줄에 `cmd`를 입력하고 Enter)
- `cd` 뒤에 폴더를 드래그앤드롭하는 방식은 Windows 터미널에서도 동일하게 동작합니다.

> 💡 **중요: 반드시 Claude Code를 설치할 때 사용한 것과 같은 터미널을 여세요**
> → Windows는 설치 방식(PowerShell / WSL / Git Bash 등)에 따라 `claude` 명령이 특정 터미널에서만 인식될 수 있습니다. 일반 `cmd` 창에서 `claude`를 쳤는데 "command not found"(또는 인식할 수 없다는 메시지)가 뜨면 고장이 아니라 **다른 터미널을 열어야 하는 신호**입니다 — 설치 때 사용한 터미널을 열어 다시 시도하세요. Windows 참가자는 강사·TA가 실습 시작 전 어떤 터미널로 설치했는지 개별로 한 번씩 확인해 주세요.

막히면 위 macOS 순서 대신 이 방법으로 TA에게 도움을 요청하세요.
