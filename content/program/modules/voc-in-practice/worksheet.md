- [ ] 주문번호/계정 식별 정보를 지우거나 가렸다
- [ ] 위 항목에 해당하는 정보가 원래 없었다 (확인함)

> 셋 중 하나라도 체크가 안 됐다면, `reviews.txt`에 붙여넣기 **전에** 지금 처리하고 오세요. 가이드 1단계의 💡 박스를 참고하세요.

**별점 열 유무**

- [ ] 있음 → `reviews.txt`에 리뷰 내용과 함께 그대로 포함시켰다
- [ ] 없음 → 괜찮습니다. 2단계 프롬프트의 4번(부정 리뷰 분석) 항목은 자동으로 건너뜁니다. 아래에 표시:
  - [ ] 별점 없이 진행함 (1~3번 결과만 받음)

**파일 준비 상태**

- [ ] `reviews.txt` 파일을 만들어 작업 폴더에 저장했다
- [ ] 터미널에서 그 폴더로 이동해 `ls`로 `reviews.txt`가 보이는 것을 확인했다
- [ ] Claude Code(`claude`)를 켰다

**대체 데이터 사용 여부** (자기 데이터를 못 가져온 경우)

- [ ] 자기 서비스 데이터로 진행함
- [ ] 강사 배포 대체 샘플로 진행함 → 오늘 결과는 연습용입니다. 다음 기회에 자기 데이터로 한 번 더 돌려 보세요.
