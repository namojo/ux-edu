## 2. 근거 대조 표

아래 표를 최소 3줄 이상 채우세요. `persona-journey.md`와 저니맵 표에서 항목을 골라 옮겨 적고, 원본 파일에서 실제로 검색한 결과를 기록합니다.

| 항목(어느 칸인지) | 적힌 내용 | 근거 번호 | 원본에서 검색했나 | 결과 | 비고 |
|---|---|---|---|---|---|
| 예: 페인포인트 ① | "카드 여러 개를 일일이 입력하기 귀찮음" | P3, P7 | ☑ | ☑ 원문과 일치　☐ 뉘앙스 다름　☐ 원문에 없음(누출) | P3.txt 3번째 문단에서 확인 |
| | | | ☐ | ☐ 원문과 일치　☐ 뉘앙스 다름　☐ 원문에 없음(누출) | |
| | | | ☐ | ☐ 원문과 일치　☐ 뉘앙스 다름　☐ 원문에 없음(누출) | |
| | | | ☐ | ☐ 원문과 일치　☐ 뉘앙스 다름　☐ 원문에 없음(누출) | |
| | | | ☐ | ☐ 원문과 일치　☐ 뉘앙스 다름　☐ 원문에 없음(누출) | |

> 결과 판정 기준
> - **원문과 일치**: 원본 파일에서 해당 발언을 그대로 찾을 수 있고, 뜻도 같다.
> - **뉘앙스 다름**: 발언은 있으나 AI가 강도를 부풀리거나(예: "그냥 그랬다"→"짜증났다") 다듬어서 살짝 달라졌다.
> - **원문에 없음(누출)**: 검색해도 그런 내용이 없다 — 스테레오타입 누출 또는 환각으로 표시하고, 팀 공유 전 반드시 수정 요청한다.

## 3. 근거 없음 / [추정] 칸 점검
