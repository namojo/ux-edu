# CX/UX 팀 AI 활용 사례집

코딩 경험이 없어도 따라 할 수 있는, Claude Code를 UX 실무에 활용하는 사례 10편입니다.
모든 사례는 **복사해 쓸 수 있는 프롬프트 + 따라 하기 단계 + 사람이 꼭 확인할 지점**을 포함합니다.

> 생성: 2026-07-26, UX 인에이블먼트 하네스 (작성 → 전문 검수 → 수정 반영 완료)

## 추천 학습 순서

처음이라면 **① → ② → ③** 순서를 권합니다. 교육 프로그램(`education/`)의 실습 순서와 같습니다.

1. **[VoC/CX 피드백 분석](voc-mining.md)** — 파일 하나 넣고 분류표 받기. 가장 빠른 성공 경험
2. **[사용자 리서치 종합](research-synthesis.md)** → **[페르소나 & 저니맵](persona-journey.md)** — 두 사례를 이어서 하면 리서치→페르소나 파이프라인이 됩니다
3. **[MVP 프로토타입](mvp-prototype.md)** — 코드 한 줄 안 쓰고 클릭되는 시제품 만들기

## 전체 사례 목록

| 사례 | 영역 | 난이도 | 이런 때 쓰세요 |
|------|------|--------|---------------|
| [사용자 리서치 종합](research-synthesis.md) | 리서치 | 중급 | 인터뷰 녹취 더미에서 어피니티 맵·인사이트를 뽑을 때 |
| [페르소나 & 저니맵](persona-journey.md) | 리서치 | 중급 | 리서치 데이터로 근거 있는 페르소나·저니맵 초안이 필요할 때 |
| [사용성 테스트 분석](usability-analysis.md) | 평가 | 중급 | 세션 노트에서 이슈 목록과 심각도 우선순위를 만들 때 |
| [VoC/CX 피드백 분석](voc-mining.md) | CX | 중급 | 리뷰·CS 티켓 수백 건에서 개선 기회를 찾을 때 |
| [UX 라이팅](ux-writing.md) | 라이팅 | 중급 | 마이크로카피 시안을 여러 개 뽑고 톤앤매너로 검수할 때 |
| [IA·내비게이션 검토](ia-review.md) | 설계 | 중급 | 메뉴 구조의 대안과 라벨 개선안이 필요할 때 |
| [경쟁사 UX 벤치마킹](competitor-bench.md) | 리서치 | 중급 | 경쟁 서비스 온보딩을 비교표 한 장으로 정리할 때 |
| [MVP 프로토타입](mvp-prototype.md) | 프로토타이핑 | 중급 | 아이디어를 클릭 가능한 시제품으로 빠르게 검증할 때 |
| [접근성 점검](a11y-audit.md) | 평가 | 중급 | 화면 HTML에서 접근성 이슈와 개선안을 받을 때 |
| [디자인 시스템 문서화](design-system-doc.md) | 시스템 | 중급 | 컴포넌트 규칙 메모를 일관된 가이드 문서로 만들 때 |

- 모든 사례는 macOS/Windows 안내를 병기했으나, 사내 표준 OS가 확정되면 해당 OS 기준으로 단순화할 수 있습니다
